# License texts for third-party crates

SPDX identifiers in [`../THIRD_PARTY_NOTICES`](../THIRD_PARTY_NOTICES) refer to the texts below where applicable.

| SPDX (or component) | File |
|---------------------|------|
| MIT | [MIT.txt](MIT.txt) |
| Apache-2.0 | [Apache-2.0.txt](Apache-2.0.txt) |
| ISC | [ISC.txt](ISC.txt) |
| BSD-3-Clause | [BSD-3-Clause.txt](BSD-3-Clause.txt) |
| Zlib | [Zlib.txt](Zlib.txt) |
| Unlicense | [Unlicense.txt](Unlicense.txt) |

For combined expressions (e.g. `MIT OR Apache-2.0`), use any license that matches the expression.

Other identifiers used in the dependency tree:

- **Unicode-3.0** — <https://www.unicode.org/license.txt>
- **BSL-1.0** (Boost) — <https://www.boost.org/LICENSE_1_0.txt>
- **CDLA-Permissive-2.0** — <https://spdx.org/licenses/CDLA-Permissive-2.0.html>
- **Apache-2.0 WITH LLVM-exception** — LLVM exception in [Apache-2.0.txt](Apache-2.0.txt) appendix (see upstream crate)
